# Home Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** Turn the home screen into Home · Groups · + · People · You under the group screen's floating bar.

**Architecture:** The bar is extracted from `GroupBar` into a generic `MullTabBar` (items, current index, + callback); `GroupBar` keeps its API on top of it. A `HomeShell` holds the four tab pages in an `IndexedStack` with the bar laid over them, exactly like `GroupScreen`. Each tab is its own `MullPage` with the brand bar (wordmark + bell only).

**Tech Stack:** Flutter, flutter_test, integration_test.

**Spec:** `docs/superpowers/specs/2026-11-10-home-tabs-design.md`

## Global Constraints

- Branch `release-1.1`. Tokens from `context.c` only; dark and light.
- Copy verbatim: "Needs you", "Recent", "Groups", "+ New group", "Settled", "People", "+ Add a friend", "You owe", "Owes you", "Square", "Friends", "Pay", "Nudge".
- Tab order and labels: Home, Groups, People, You. + semantic label "Add an expense".
- `flutter test` green and `flutter analyze` clean after every task.

## Review Focus

- **Two bars on screen at once.** A group pushed over the home shell must cover the home bar fully, with only the group's bar visible. Test in Task 7.
- **Toasts on both bars.** Closing a group must not drop toasts back onto the home bar's +. Test in Task 2.
- **A new user with no groups.** The + starts a group and never opens an empty picker. Test in Task 7.
- **A long Needs-you list.** Ten cards collapse to one card plus the stack behind it, and tapping expands them in place. Test in Task 3.
- **Android Back on a non-Home tab.** It goes to Home, not out of the app. Test in Task 2.
